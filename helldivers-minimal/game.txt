## Controls

| Action | Input |
|--------|-------|
| Move | `W A S D` |
| Aim / Fire | Mouse + LMB |
| Sprint | `Shift` |
| Reload | `R` |
| Stratagems | Hold `Ctrl` + directional WASD |
| Pause | `Esc` |
| Fullscreen | Button in top-right |

**Stratagem codes** (hold Ctrl): ↓↓↑→ Resupply · →→↑ Orbital · ↑↓→←↑ Reinforce · ↑→→ Eagle
